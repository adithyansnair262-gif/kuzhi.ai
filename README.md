# KUZHI.AI

KUZHI.AI is a playful circularity intelligence web app that analyzes holes in food specimens such as vada, appam, donuts, and other circular foods.

## Features

- Upload an image directly in the browser
- Detect potential holes
- Calculate circularity
- Calculate centroid offset
- Calculate radial deviation
- Calculate coefficient of variation
- Estimate hole diameter
- Generate a Kuzhi Score
- Visualize the result with a chalkboard-style interface
- Runs entirely in the browser

## Tech Stack

- HTML
- CSS
- JavaScript
- Canvas API

## Run Locally

Open `index.html` in a browser, or use VS Code Live Server.
