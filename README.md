# Project Description

KUZHI.AI is a playful Circularity Intelligence Platform designed to analyze the holes found in circular foods such as vada, appam, donuts, and poori.

The application uses browser-based image analysis to detect a hole and mathematically evaluate its circularity, centering, symmetry, and other geometric properties — because apparently, even a kuzhi deserves scientific analysis.

---

# The Problem (that doesn't exist)

For centuries, people have been eating vadas, appams, donuts, and other foods with holes without properly measuring them.

Nobody knows:

- How perfectly circular the hole is
- Whether the hole is actually centered
- How symmetrical the hole is
- How large the hole really is
- Whether one vada has a superior kuzhi compared to another

This completely unnecessary problem clearly needed a completely unnecessary solution.

---

# The Solution (that nobody asked for)

KUZHI.AI allows users to upload an image of a food specimen and performs a mathematical analysis of its hole.

The system checks whether a hole exists and calculates several properties including:

- Circularity
- Centroid offset
- Radial deviation
- Coefficient of variation
- Estimated hole diameter
- Overall Kuzhi Score

The results are presented through a fun and visually engaging interface.

**KUZHI.AI — because every hole deserves to be judged mathematically.**

# Implementation

## For Software

The application follows a browser-based image-analysis workflow.

1. The user opens the KUZHI.AI Circularity Inspector.
2. The user uploads a photograph of a food specimen.
3. The image is processed directly inside the browser.
4. The Canvas API is used for image analysis.
5. The system checks for the presence of a potential hole.
6. The detected hole is analyzed mathematically.
7. Circularity, centroid offset, radial deviation, coefficient of variation, and estimated diameter are calculated.
8. The measurements are combined to generate a Kuzhi Score.
9. The final analysis is displayed to the user.

No backend server or external AI service is required.
